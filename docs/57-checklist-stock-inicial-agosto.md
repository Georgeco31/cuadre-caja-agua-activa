# 57 - Checklist de stock inicial de agosto

## Uso de esta plantilla

Esta hoja es para George y la oficina. Se completa con conteo físico real antes
de registrar el stock inicial de agosto de 2026.

No escribir cantidades estimadas. Si algo no se pudo contar, llevarlo a
Pendientes. Una casilla vacía no se reemplaza por cero salvo que el conteo
físico haya confirmado cero.

## Antes de contar

- [ ] Se detuvieron temporalmente entradas, salidas, producción, cargas,
  retornos y ventas que puedan cambiar el conteo.
- [ ] Se definió una hora de corte.
- [ ] Los productos activos fueron revisados.
- [ ] Las ubicaciones de bodega, carro y oficina fueron identificadas.
- [ ] Cada ubicación de vehículo corresponde al carro correcto.
- [ ] Las unidades de los insumos fueron confirmadas.
- [ ] Se separaron producto terminado, insumo consumible y envase retornable.
- [ ] No se modificaron precios, costos ni fórmulas.

Reglas:

- usar una fila por producto y ubicación;
- no sumar bodega y carro en una sola fila;
- escribir la presentación exacta;
- si un producto no se contó, llevarlo a Pendientes;
- el bidón lleno y el envase vacío retornable no deben mezclarse sin una regla
  aprobada.

- comprobar que el vehículo y su ubicación están correctamente relacionados.
