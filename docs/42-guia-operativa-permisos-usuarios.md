# 42 - Guía operativa de permisos y usuarios

## Propósito

Esta guía explica qué cuenta debe usar cada persona en Agua Activa ERP y qué
hacer cuando una tarea requiere autorización.

Cada persona debe ingresar con su propia cuenta. No se deben compartir usuarios
ni contraseñas.

## Administrador/auditor

La cuenta de administrador/auditor está destinada a George o a la persona que
él autorice expresamente.

Puede:

- consultar y operar todos los módulos;
- administrar usuarios;
- gestionar empleados, control laboral y nómina;
- configurar precios;
- revisar el panel gerencial;
- consultar reportes sensibles;
- descargar Excel y PDF;
- gestionar fórmulas y consumos de producción;
- realizar correcciones, anulaciones, ajustes y cambios críticos.

La cuenta de administrador no debe usarse para el trabajo operativo diario.
Reservarla para tareas de control reduce errores y deja más claro quién realizó
cada acción.

## Operador

La cuenta de operador está destinada al trabajo diario de oficina y operación.

Puede:

- ver su panel operativo;
- abrir o crear el cuadre diario;
- registrar conteos de caja;
- registrar gastos del cuadre;
- cerrar el cuadre diario;
- consultar el historial básico de caja;
- crear y consultar clientes;
- registrar ventas de contado;
- registrar ventas a crédito;
- registrar cobros y abonos;
- consultar cuentas por cobrar;
- consultar productos;
- registrar producción diaria;
- consultar inventario;
- registrar entradas y salidas manuales de inventario sin costo;
- consultar los demás módulos operativos mostrados en su panel.

## Lo que el operador no debe intentar

El operador no debe:

- corregir un cuadre que ya fue cerrado;
- anular ventas, cobros, compras u otras operaciones;
- cambiar precios;
- crear o modificar productos, rutas, vehículos, proveedores o ubicaciones;
- registrar ajustes de inventario;
- ingresar o cambiar costos;
- aplicar producción al inventario;
- cambiar fórmulas o registrar consumo de insumos;
- administrar empleados, asistencia, anticipos, préstamos o nómina;
- administrar usuarios o roles;
- abrir el panel gerencial;
- abrir reportes sensibles;
- descargar Excel o PDF;
- intentar evitar o saltar el mensaje de acceso restringido.

Si una opción no aparece en el panel del operador, no significa que el sistema
esté dañado. Puede tratarse de una tarea reservada al administrador/auditor.

## Si aparece “No tienes permiso”

1. No repitas la acción varias veces.
2. No uses la cuenta de otra persona.
3. Anota qué tarea estabas realizando y, si corresponde, el número o la fecha
   del registro.
4. Solicita autorización a George.
5. Espera a que George revise la operación o la realice con su propia cuenta.

No es necesario copiar mensajes técnicos, contraseñas ni información sensible.
Una descripción breve de la tarea es suficiente.

## Cuándo pedir autorización a George

Solicita autorización antes de:

- corregir información de un cuadre cerrado;
- anular una venta, cobro u otra operación;
- cambiar un precio;
- realizar un ajuste o cambio de costo en inventario;
- cambiar fórmulas o consumos de producción;
- modificar información de personal o nómina;
- crear o cambiar cuentas de usuario;
- descargar o entregar reportes sensibles;
- realizar una acción que el sistema marque como restringida;
- usar la cuenta de administrador por cualquier motivo.

## Usuarios y contraseñas

- Cada persona debe tener una cuenta individual.
- No se deben compartir contraseñas por chat, papel visible ni llamadas.
- No se debe dejar una sesión abierta cuando la persona se aleja del equipo.
- Al terminar el turno, cerrar la sesión.
- Si se sospecha que otra persona conoce la contraseña, avisar a George.
- Nunca guardar una contraseña en un documento compartido.

## Uso recomendado de las cuentas

| Situación | Cuenta recomendada |
| --- | --- |
| Caja, clientes, ventas, cobros, producción diaria o entrada/salida de inventario | Operador |
| Usuarios, precios, empleados, nómina o fórmulas | Administrador/auditor |
| Correcciones, anulaciones, ajustes o costos | Administrador/auditor |
| Panel gerencial, Excel o PDF | Administrador/auditor |
| Trabajo diario habitual | Operador |

## Reportes y exportaciones

Los reportes sensibles, el panel gerencial y las descargas Excel/PDF son solo
para administrador/auditor.

El operador puede consultar la información operativa que aparece en sus
módulos permitidos, pero no debe pedir prestada una cuenta administrativa para
descargar o consultar información restringida.

Cuando una persona externa solicite un reporte, George debe revisar primero:

- quién lo solicita;
- para qué se usará;
- qué período necesita;
- si contiene información sensible;
- por qué medio se entregará.

## Recordatorio diario

Antes de empezar:

- confirma que estás usando tu propia cuenta;
- verifica que el nombre o rol mostrado sea el correcto.

Durante el trabajo:

- usa únicamente las opciones disponibles para tu rol;
- revisa los datos antes de guardar o cerrar;
- solicita ayuda cuando una tarea sea restringida.

Al terminar:

- finaliza la tarea en curso;
- cierra la sesión;
- no dejes contraseñas ni reportes visibles.

## Uso durante el piloto interno

Esta guía sigue siendo la referencia de permisos. Para el trabajo del piloto,
usar además:

- [`44-guia-piloto-secretaria-operador.md`](44-guia-piloto-secretaria-operador.md)
  para el flujo diario de oficina;
- [`45-guia-piloto-george-admin.md`](45-guia-piloto-george-admin.md) para la
  revisión y contingencia de George;
- [`46-registro-incidencias-piloto.md`](46-registro-incidencias-piloto.md) para
  documentar bloqueos o diferencias.

El piloto no amplía los permisos de `operator`. Un bloqueo se revisa con George;
no se resuelve prestando la cuenta administrativa ni cambiando el rol.

## Regla principal

La cuenta de operador es para operar. La cuenta de administrador/auditor es para
autorizar, configurar, corregir y controlar.

Ante una duda, detener la acción y consultar a George.
